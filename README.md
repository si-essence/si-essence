# Hi, I'm Issah 👋

I build **MCP connectors**: small servers that let AI assistants like Grok Bot and Claude work with self-hosted apps and public APIs. I'm based in Ghana and build for anyone, anywhere.

Every connector is MIT licensed, written in TypeScript, and built the same way: you pick the toolsets you need, writes stay off unless you turn them on and confirm them, and you can preview changes as a dry run first.

## Self-hosted apps

- [immich-mcp](https://github.com/si-essence/immich-mcp): assets, albums, people and search for Immich
- [kavita-mcp](https://github.com/si-essence/kavita-mcp): libraries, series, reading lists and progress for Kavita
- [audiobookshelf-mcp](https://github.com/si-essence/audiobookshelf-mcp): libraries, items, podcasts and more for Audiobookshelf
- [seafile-mcp](https://github.com/si-essence/seafile-mcp): libraries, files, shares and admin for Seafile
- [linkding-mcp](https://github.com/si-essence/linkding-mcp): bookmarks in Linkding
- [grocy-mcp](https://github.com/si-essence/grocy-mcp): stock, shopping lists, chores and recipes for Grocy
- [solidtime-mcp](https://github.com/si-essence/solidtime-mcp): time entries, projects and reports for Solidtime

- [changedetection-mcp](https://github.com/si-essence/changedetection-mcp): website change and restock watches in changedetection.io
